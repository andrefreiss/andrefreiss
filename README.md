## Projetos em destaque

### [Day Flow](https://github.com/andrefreiss/day-flow)

Aplicação full stack para organizar tarefas, subtarefas e categorias e acompanhar o progresso diário.

Principais características:

- Frontend com React e TypeScript
- API REST desenvolvida com NestJS
- PostgreSQL e Prisma
- Autenticação usando cookie `httpOnly`
- Controle de acesso aos dados por usuário
- Testes unitários e end-to-end
- Integração contínua com GitHub Actions
- Ambiente de desenvolvimento com Docker

**Status:** em desenvolvimento ativo.

### [Laravel Todo List](https://github.com/andrefreiss/To-Do-List---Laravel-Tailwind-CSS)

Aplicação para gerenciamento de tarefas desenvolvida com PHP, Laravel, Tailwind CSS e banco de dados relacional.

O projeto faz parte dos meus estudos e da evolução contínua no ecossistema Laravel.

### [Tic-Tac-Toe Minimax AI](https://github.com/andrefreiss/tictactoe-minimax-ai)

Jogo da velha desenvolvido com JavaScript e arquitetura modular. A inteligência artificial utiliza o algoritmo Minimax para analisar as jogadas possíveis e escolher a melhor estratégia.
