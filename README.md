## 👨‍💻 Sobre mim

Sou desenvolvedor Full Stack com experiência profissional em **PHP** e desenvolvimento de aplicações web.

Também trabalho com o ecossistema **TypeScript**, utilizando React e NestJS para desenvolver interfaces modernas, APIs REST, autenticação, integrações e aplicações conectadas a bancos de dados relacionais.

- 💼 Trabalho profissionalmente com PHP
- 🚀 Atualmente desenvolvo o **Day Flow**
- 🧪 Tenho interesse em testes automatizados e qualidade de código
- ⚙️ Estudo arquitetura, CI/CD e boas práticas de desenvolvimento
- 🤝 Aberto a novas oportunidades e desafios profissionais

> Os códigos dos sistemas em que trabalho profissionalmente não estão publicados neste perfil por pertencerem às empresas e aos clientes envolvidos.
